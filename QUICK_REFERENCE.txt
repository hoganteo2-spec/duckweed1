🔧 GOOGLE DRIVE SETUP
═══════════════════════════════════════════════════════════════════════════════

Option 1: OAuth 2.0 (Personal Use)
  1. Go to https://console.cloud.google.com/
  2. Create project → Enable Google Drive API
  3. Create OAuth 2.0 credentials (Desktop app)
  4. Download credentials.json
  5. Run: python3 advanced_segment.py --upload --credentials credentials.json

Option 2: Service Account (Automated)
  1. Create service account in Google Cloud Console
  2. Download JSON key file
  3. Set: export GOOGLE_APPLICATION_CREDENTIALS=/path/to/key.json
  4. Run: python3 advanced_segment.py --upload

✨ ALGORITHM OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

Water Detection:
  Image → Grayscale → Edge Detection → Hough Circles/Ellipse → Water Mask

Duckweed Segmentation:
  Image → HSV → Green Threshold → Remove Reflections/Shadows →
  Morphological Ops → Contour Filtering → Clip to Water → Final Mask

Coverage Calculation:
  Coverage % = (Duckweed Pixels in Water / Total Water Pixels) × 100

🐞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ImportError: No module named 'google'
  → pip3 install google-auth-oauthlib google-api-python-client

No water detected
  → Check image has clear water container
  → Enable debug: python3 advanced_segment.py --debug
  → Check segmentation.log for details

Google Drive upload fails
  → Verify credentials file is valid
  → Check network connectivity
  → See INSTALLATION_GUIDE.md section "Google Drive Upload Failed"
