🎯 WHAT THIS SYSTEM DOES
═══════════════════════════════════════════════════════════════════════════════

This is a complete HIGH-ACCURACY duckweed monitoring system that:

1. ✅ Detects water containers (circular, oval, or polygon shapes)
2. ✅ Segments green duckweed using advanced HSV color detection
3. ✅ Handles shadows, reflections, sparse and dense duckweed
4. ✅ Calculates duckweed coverage percentage
5. ✅ Generates 4 types of output images (masks, contours, annotated)
6. ✅ Logs all results to CSV for analysis
7. ✅ Automatically uploads results to Google Drive
8. ✅ Processes batch images or single images

📊 ALGORITHM SUMMARY
═══════════════════════════════════════════════════════════════════════════════

Water Detection:
  1. Convert image to grayscale
  2. Apply edge detection (Canny)
  3. Use Hough Circle Detection OR ellipse fitting
  4. Generate binary water mask

Duckweed Segmentation:
  1. Convert to HSV color space
  2. Apply green color threshold
  3. Remove reflections (bright pixels) & shadows (dark pixels)
  4. Morphological opening (remove noise)
  5. Morphological closing (fill holes)
  6. Filter by contour area
  7. Clip to water region
  8. Generate binary duckweed mask

Coverage Calculation:
  Coverage % = (duckweed pixels in water / total water pixels) × 100

Google Drive Upload:
  • OAuth 2.0 or Service Account authentication
  • Automatic folder creation
  • Upload all output images
  • Log success/failure

🔧 SETUP GOOGLE DRIVE INTEGRATION (OPTIONAL)
═══════════════════════════════════════════════════════════════════════════════

Option 1: OAuth 2.0 (Recommended for personal use)
  1. Go to https://console.cloud.google.com/
  2. Create a new project
  3. Enable "Google Drive API"
  4. Create "OAuth 2.0 Client ID" credentials (Desktop application)
  5. Download credentials.json
  6. Run: python3 advanced_segment.py --upload --credentials credentials.json

Option 2: Service Account (For automated systems)
  1. Create service account in Google Cloud Console
  2. Download JSON key file
  3. Set: export GOOGLE_APPLICATION_CREDENTIALS=/path/to/key.json
  4. Run: python3 advanced_segment.py --upload
